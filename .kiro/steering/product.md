# G2M-Export プロダクト概要

Git to Markdown Exporter。ローカルの Git リポジトリを再帰的にスキャンし、AI が理解しやすい「1ファイル統合 Markdown」へエクスポートする CLI ツール。

## 主な機能

- `.git` ディレクトリを直接読み取り、リモート URL・ブランチ名を取得（`git` コマンド不要）
- 各ファイルセクションに GitHub/Bitbucket/GitLab の Web ビュー URL を自動付与
- `g2m_config.yaml` による除外パターン・バイナリ拡張子の設定
- ファイルサイズ制限による自動分割出力
- バイナリファイルの自動判定と除外

## 参照プロジェクト

C2M-Export および J2M-Export のアーキテクチャパターンとファイル命名規則に従う。

## コミュニケーション

すべてのコミュニケーション（コメント、PR、docstring、ログ出力）は日本語で行う。
